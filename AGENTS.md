# Project Agent Instructions

Before creating, editing, reviewing, or refactoring any Java source or test in this repository, read and follow the project skill at `.skills/java-coding-standard/SKILL.md`.

This requirement applies to every `.java` change, including generated patches, style-only changes, and test code. Treat the skill's rules as mandatory unless a user instruction explicitly overrides a specific rule.

Before creating, amending, or proposing any Git commit in this repository, read and follow the project skill at `.skills/git-standard/SKILL.md`.

This requirement applies to every future commit, including commit-message reviews and branch-name decisions. Treat the skill's rules as mandatory unless a user instruction explicitly overrides a specific rule.
